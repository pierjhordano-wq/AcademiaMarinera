# AcademiaMarinera

Sitio web de la academia de baile Hno's Piero's, especializada en Marinera Norteña.

## Ver el sitio

Abre `index.html` en un navegador. La carpeta `assets/` contiene el logotipo y las fotografías utilizadas en la página.

## Publicación

Repositorio preparado para GitHub Pages desde la rama `main`, usando la carpeta raíz.
